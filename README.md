# La Lupita

Website for La Lupita, a family-run Mexican restaurant at 4 W 4th St, Bethlehem, PA.

Plain static HTML, CSS and JS. No build step. Deployed on Vercel (`vercel.json` holds clean URLs and security headers).

- `index.html` home page
- `menu.html` full menu (the table QR codes point here)
- `privacy.html`, `terms.html`, `accessibility.html` legal pages
- `assets/` styles, script, photos and the logo wordmark
